Dans addEventListener, écrire le nom de la fonction sans (). Le navigateur l’appelle quand l’événement arrive.

function init() {
    document.querySelector(".bouton").addEventListener("click", changerTexte);
}

function changerTexte() {
    document.querySelector(".bouton").textContent = "Tu as cliqué !";
}

3 · Styles DOM

Je veux…Exemple
Changer la couleur du textedocument.querySelector(".texte").style.color = "blue";
Utiliser une couleur hexadécimaledocument.querySelector(".texte").style.color = "#DC143C";
Changer le fonddocument.querySelector(".carte").style.backgroundColor = "yellow";
Choisir le style de borduredocument.querySelector(".carte").style.borderStyle = "solid";
Choisir la couleur de borduredocument.querySelector(".carte").style.borderColor = "red";
Choisir la largeur de borduredocument.querySelector(".carte").style.borderWidth = "2px";
Changer la largeurdocument.querySelector(".carte").style.width = "200px";
Changer la hauteurdocument.querySelector(".carte").style.height = "100px";
Changer l’opacitédocument.querySelector(".carte").style.opacity = 0.5;
Masquer l’élémentdocument.querySelector(".carte").style.display = "none";
Réafficher l’élémentdocument.querySelector(".carte").style.display = "block";
Déplacer depuis la gauchedocument.querySelector(".carte").style.left = "20px";
Déplacer depuis le hautdocument.querySelector(".carte").style.top = "30px";
À retenir

Les dimensions et déplacements ci-dessus ont une unité : "20px". L’opacité va de 0 (transparent) à 1 (opaque). left et top nécessitent un positionnement CSS adapté, par exemple position: relative. display = "none" retire aussi la place occupée; "block" réaffiche en bloc.

4 · Classes

Je veux…Exemple
Ajouter une classedocument.querySelector(".carte").classList.add("active");
Retirer une classedocument.querySelector(".carte").classList.remove("active");
Basculer une classedocument.querySelector(".carte").classList.toggle("active");
À retenir

Dans classList, écrire le nom sans point. toggle ajoute la classe absente ou retire la classe présente. Conserver la classe qui sert à retrouver l’élément. querySelector cible seulement le premier élément correspondant.

5 · Attributs

Je veux…Exemple
Lire le texte alternatiflet texteAlternatif = document.querySelector(".image").alt;
Ajouter ou remplacer le texte alternatifdocument.querySelector(".image").alt = "Bébé requin";
Vider le texte alternatifdocument.querySelector(".image").alt = "";
À retenir

Les attributs figurent dans la balise ouvrante HTML. L’affectation remplace la valeur précédente.
