Exercice 2 - C'est quoi un bouton ? 😵

Le but de cet exercice est de rendre les boutons dans la page interactifs.

  • Le premier bouton change du texte lorsque cliqué.
  • Le deuxième bouton lance une alerte lorsque survolé.
  • Le troisième bouton imprime du texte dans la console lorsqu'il n'est plus survolé.
Saviez-vous que les écureuils oublient 50% des noix qu'ils cachent ? 🥜😩
