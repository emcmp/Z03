Exercice 3 - Peut-on compter sur toi ? 🤔

Le but de cet exercice est d'ajouter deux écouteurs d'événement :

  • En cliquant sur 🔼, la valeur du compteur est augmentée de 1.
  • En cliquant sur 🔽, la valeur du compteur est réduite de 1.

Lorsqu'on appuie sur une flèche, le contenu textuel de l'élément au centre (Qui contient le texte « 0 » pour le moment) doit être mis à jour pour afficher la nouvelle valeur du compteur.
