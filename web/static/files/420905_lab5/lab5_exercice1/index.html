Exercice 1 - Kossé so un bouléin

• Pour cet exercice (et les suivants), vous pouvez vous servir des boutons dans la page pour modifier les valeurs de plusieurs variables globales.

• Vous aurez à programmer en utilisant des if. Vos if s'exécuteront (ou pas) selon la valeur que vous aurez donné aux variables globales.

Utilisez les boutons 🔄, 🔽 et 🔼 pour modifier les valeurs des variables globales. Cela permettra de mieux tester vos fonctions en essayant différentes possibilités.

Nom de la variable Valeur
gJeSuisFatigue false 🔄
gAliment brocoli 🔄
gPrixPantalons 🔽 50 🔼

Cliquez sur ces boutons pour tester les trois fonctions.
