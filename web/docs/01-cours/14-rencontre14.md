# Rencontre 14 — Examen formatif

Cette rencontre est consacrée à la **pratique et à la révision** avant l'examen final.

Vous pourrez réaliser un **examen formatif** pour vous exercer sur les compétences vues en JavaScript, dans des situations différentes de celles de l'examen final. Vous pourrez ensuite **vous autocorriger** à l'aide du corrigé.

:::info Documents à venir
Le formatif et son corrigé seront ajoutés ici lorsqu'ils seront prêts. Les deux téléchargements ne sont pas encore disponibles.
:::

## 1. Faire l'examen formatif

**Examen formatif — ZIP étudiant : à venir**

Lorsque le fichier sera disponible :

1. Téléchargez le ZIP du formatif et extrayez son contenu.
2. Ouvrez le fichier `index.html` pour accéder à l'accueil et aux modules.
3. Faites les questions en utilisant les notions du cours et votre aide-mémoire.
4. Essayez de terminer toutes les questions **avant de consulter le corrigé**.

## 2. Vous autocorriger

**Corrigé du formatif — ZIP de correction : à venir**

Une fois le formatif terminé, utilisez le corrigé pour comparer vos réponses, tester les exercices et identifier les notions à retravailler. Ne vous limitez pas à copier le code : cherchez à comprendre pourquoi une solution fonctionne.

## 3. Pratique, rattrapage et révision

Vous pouvez également profiter de cette rencontre pour terminer un travail en cours, reprendre un exercice ou revoir les notions qui vous semblent plus difficiles.

Aucune nouvelle notion essentielle n'est introduite pendant cette rencontre.
