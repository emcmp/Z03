# Rencontre 11 - Boucles

:::warning Séquence provisoire
Le contenu hérité sur les boucles doit être simplifié. Une forme principale de boucle sera privilégiée pour limiter la surcharge.
:::

## Noyau prévu

- comprendre le besoin de répétition;
- écrire et lire une boucle simple;
- utiliser une boucle pour traiter plusieurs valeurs ou éléments;
- pratiquer le débogage de conditions de boucle simples.

`do...while` et les variantes plus complexes sont de bons candidats à sortir du noyau obligatoire.
