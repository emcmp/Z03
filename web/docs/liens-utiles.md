# Liens utiles

Voici des ressources et des liens qui pourront vous être utiles pendant la session pour le cours de **programmation Web**.

## Valider son code HTML

- **[Validateur HTML du W3C](https://validator.w3.org/)** — permet de vérifier la validité d'un document HTML et de repérer plusieurs erreurs de structure ou de syntaxe.

## Apprendre et consulter des références

- **[W3Schools](https://www.w3schools.com/)** — site de formation et de référence pour HTML, CSS, JavaScript, jQuery et plusieurs autres technologies Web. Le site est en anglais par défaut, mais la langue peut être changée.

## Caractères spéciaux en HTML

- **[Named character references — WHATWG](https://html.spec.whatwg.org/multipage/named-characters.html)** — liste officielle des références de caractères nommés supportées en HTML.

## Générateurs CSS

Ces outils peuvent être pratiques pour expérimenter avec certaines propriétés CSS et observer le code produit.

### Ombres (`box-shadow`)

- **[Box Shadow CSS Generator — HTML CSS JS](https://html-css-js.com/css/generator/box-shadow/)**
- **[Box Shadow Generator — CSSmatic](https://www.cssmatic.com/gen-box-shadow.html)**

### Transitions

- **[CSS Transition Generator — Web Code Tools](https://webcode.tools/css-generator/transition)**

:::tip Utiliser les générateurs pour comprendre
Un générateur CSS peut vous aider à expérimenter, mais prenez le temps de lire le code qu'il produit et de comprendre les propriétés utilisées avant de l'intégrer à votre projet.
:::
