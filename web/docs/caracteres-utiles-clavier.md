# Caractères utiles au clavier

En programmation Web, plusieurs caractères reviennent constamment : `<`, `>`, `{`, `}`, `"`, `/`, `;`, etc. Cette fiche permet de retrouver rapidement les combinaisons de touches les plus utiles.

:::info Disposition du clavier
Les combinaisons ci-dessous correspondent à la disposition Windows **Canadien français**. `AltGr` correspond à la touche **Alt droite**.
:::

## Les indispensables pour HTML

| Caractère | Nom | Touches |
| --- | --- | --- |
| `<` | inférieur / chevron ouvrant | touche `<` |
| `>` | supérieur / chevron fermant | `Maj` + `<` |
| `"` | guillemet double | `Maj` + `2` |
| `/` | barre oblique | `Maj` + `3` |
| `=` | signe égal | touche `=` |
| `!` | point d'exclamation | `Maj` + `1` |
| `-` | tiret | touche `-` |
| `_` | trait de soulignement | `Maj` + `-` |

Exemple :

```html
<p class="important">Bonjour!</p>
```

## Les indispensables pour CSS

| Caractère | Nom | Touches |
| --- | --- | --- |
| `{` | accolade ouvrante | `AltGr` + touche `` ` `` |
| `}` | accolade fermante | `AltGr` + `<` |
| `:` | deux-points | `Maj` + `;` |
| `;` | point-virgule | touche `;` |
| `#` | dièse | touche `#` à gauche du `1` |
| `.` | point | touche `.` |
| `(` | parenthèse ouvrante | `Maj` + `9` |
| `)` | parenthèse fermante | `Maj` + `0` |
| `*` | astérisque | `Maj` + `8` |

Exemple :

```css
.important {
  color: red;
}
```

## Autres caractères utiles

| Caractère | Nom | Touches |
| --- | --- | --- |
| `@` | arobase | `AltGr` + `2` |
| `&` | esperluette | `Maj` + `7` |
| `+` | signe plus | `Maj` + `=` |
| `'` | apostrophe / guillemet simple | `Maj` + `,` |
| `\` | barre oblique inverse | `AltGr` + `#` |
| `|` | barre verticale | `Maj` + `#` |
| `~` | tilde | `AltGr` + `;` |

:::tip À retenir
Pour HTML, commencez par mémoriser surtout **`<`**, **`>`**, **`"`**, **`/`** et **`=`**. Pour CSS, ajoutez ensuite **`{`**, **`}`**, **`:`** et **`;`**.
:::
